# Even or Odd

**Plataforma:** [Codewars](https://www.codewars.com/kata/53da3dbb4a5168369a0000fe)  
**Dificuldade:** 8 kyu  
**Tags:** Mathematics, Fundamentals

## Desafio

Create a function that takes an integer as an argument and returns "Even" for even numbers or "Odd" for odd numbers.

## Código original

```python
def even_or_odd(number):
    pass
```

## Solução — Python

```python
def even_or_odd(number):
  if number % 2 == 0:
    return "Even"
  else:
    return "Odd"
```
