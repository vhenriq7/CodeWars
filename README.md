# CodeWars

Repositório de exercícios de programação resolvidos no [Codewars](https://www.codewars.com/), organizados por linguagem e nível.

## Organização

- `Python/8kyu/`: exercícios iniciantes em Python.
- `Java/8kyu/`: exercícios iniciantes em Java.

As soluções devem ser adicionadas somente após a resolução dos desafios.
